# Patrix — Original-functionality reskin

هذه النسخة مبنية من **APK الأصلي نفسه** مع الحفاظ على الكود العملي الموجود داخله، ثم تغيير الهوية المرئية إلى Patrix.

## النسخة الوظيفية

ملف `releases/Patrix-v1-release.apk` يحافظ على مكونات التطبيق الأصلي، بما فيها `VpnService`، و`TProxyService`، والمكتبات native `libhev-socks5-tunnel.so` و`libm3.so`، والقائمة العائمة التي تستخدم صلاحية الظهور فوق التطبيقات، وتشغيل Free Fire، والوظائف الثلاث الموجودة داخل القائمة.

تم تغيير الاسم الظاهر إلى `Patrix`، واستبدال صور الهوية بشعار Patrix، وتغيير النصوص المرئية المرتبطة بالهوية القديمة، وتحديث رابط Telegram إلى:

https://web.telegram.org/k/#@Just_AbDoS

الـAPK يستخدم package الظاهر `com.patrix.app`، مع بقاء أسماء بعض classes الداخلية كما كانت داخل التطبيق الأصلي لضمان عدم كسر تدفق الـVPN والـnative bridge أثناء إعادة البناء.

## ما لم يتغير

لم أستبدل منطق الـVPN أو الـTProxy أو القائمة العائمة بواجهة وهمية. هذه النسخة هي reskin وظيفي للتطبيق الأصلي. كذلك لم أغيّر خادم التحقق الأصلي إلى Supabase داخل هذا الـAPK، لأن ذلك سيغيّر مسار المصادقة وقد يكسر الوظيفة العملية؛ Supabase المجهز في المشروع السابق يبقى طبقة منفصلة إلى أن يتم توفير source code أو مواصفة توافق الخادم الأصلي.

## التحقق

تمت إعادة البناء عبر Apktool، وتم الحفاظ على ملفات native لمعمارتي `arm64-v8a` و`armeabi-v7a`. تم توقيع الـAPK والتحقق منه عبر APK Signature Scheme v1/v2/v3. الاختبار النهائي على جهاز Android فعلي مطلوب للتأكد من سلوك VPN والصلاحيات الخاصة بالجهاز المستهدف.

## المصدر الأولي

مجلد `app/` هو prototype واجهة مستقل تم إنشاؤه في المرحلة السابقة. أما الـAPK الوظيفي الحالي فهو الملف الموجود في `releases/` والمبني على التطبيق الأصلي.
